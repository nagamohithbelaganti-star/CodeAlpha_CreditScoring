# CodeAlpha Credit Scoring Model 💳

A machine learning web application built with Python, Scikit-learn, and Streamlit to predict credit score classification.

---

## 📌 Project Overview
This project evaluates applicant creditworthiness based on financial parameters such as income, loan amount, credit history, and outstanding debt using a trained `RandomForestClassifier` model.

## 🛠️ Tech Stack
* **Language:** Python
* **Machine Learning:** Scikit-learn, Pandas, NumPy
* **Web Framework:** Streamlit
* **Version Control:** Git & GitHub Desktop

---

## 🚀 Features
- **Interactive UI:** Easy input fields for user financial details.
- **Instant Predictions:** Real-time credit evaluation and risk group classification.
- **Model Execution:** Pre-trained Random Forest Classifier integrated directly into `app.py`.
